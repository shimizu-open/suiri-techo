# 教材（手引き）の中身の書き方

元は `requirements.md` の 4-7（手引き）と 3-3（ホームズの思考の技能との対応）、`data-model.md` の 4（教材のファイルの形）、調査 R1（ホームズの思考法）。

## 置き場所

- 教材は表ではなくファイル：`database/data/guide/skills.json`（10の技能 S1〜S10）・`scenes.json`（名推理カード 22件前後）・`practices.json`（練習メニュー 11種）・`reasoning.json`（演繹・帰納・アブダクションの説明）。項目の名前は `data-model.md` の 4 のとおり。読み込みは `App\Support\Guide\GuideLibrary`（キャッシュして返す）。
- 中身をコードや Blade に直書きしない。利用者の推理だけを `scene_attempts` に保存する。

## 引用と要約

- **英語の引用は Project Gutenberg の本文から短く**（1〜3文）。必ず作品名と章を添える（`quote_source`・`chapter`。例：*The Sign of Four*, Chapter 1）。本文は原文のまま写し、言い換えない。
- **日本語は自前の要約**。既存の日本語訳の文を写さない・なぞらない（訳者の著作物）。作品名の日本語は広く通っている題名でよい（『四つの署名』『赤毛組合』）。作品名は『』でくくる。
- 引用の英文に日本語訳を付けるときも自前の訳にする。

## 中身の決まり

- **ホームズが外した場面も混ぜる**（『黄色い顔』の「ノーベリ」など。`is_mistake: true`）。正しく当てる話だけにしない。外れから直す姿を見せる。
- **効果を誇張しない**。「これで推理力が身につく」「頭が良くなる」とは書かない。書けるのは「観察・仮説・予想・確かめる・振り返る、の練習」まで（`bin/check` が画面と教材の JSON で、使わない言葉を止める）。
- 医療の判断に見える言葉（診断・治療・効く…）を書かない。ワトソンが医者である場面でも、言い方を選ぶ（作品名『入院患者』など『』の中は通る）。
- 説明は大人向け（`body`）と子ども向け（`kid_body`・`kid_hint`・`kid_description`）を分ける。子ども向けは words.md の「子ども向け」の言い換えを使う。
- 練習の例は3つの場面（大人・子ども・施術者）に。施術者の例は「自分が見たこと・ご本人の言葉・自分の見立て・次回確かめること」の形にし、お客さまを特定できる書き方・効果を言う書き方をしない。
- 演繹・帰納・アブダクションの言葉は手引きの画面（`views/guide`・`components/guide`）と `reasoning.json` だけで使う。毎日の画面には出さない。
- 練習メニューの `prompts`（事件を作るときの問いかけ）は、毎日の画面に出るので、難しい言葉を使わない。

## 確かめ方

- JSON を変えたら、形の検査のテスト（項目がそろっているか・キーが重ならないか・技能のキーが S1〜S10 にあるか）を通す。
- 引用は Gutenberg の本文と一字一句同じか、出典の章が合っているかを見直す。
