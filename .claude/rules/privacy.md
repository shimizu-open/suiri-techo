# 個人情報・注意書き・法律の線

元は調査 R5（法律・個人情報）の 9 章と `requirements.md` の 5・6。

## 要配慮個人情報を持たない設計

- **他人（お客さま）を表す表・列・クラスを作らない**（`customer`・`patient`・`client`・`karte`・顧客 ID・カルテ機能。`bin/check` が名前を止める）。すべては利用者を軸にし、`user_id` で絞る。
- 病名・病気のリスク・体の状態の判定をアプリが出さない。病名辞書・症状チェック・施術の効果の判定を作らない。
- 生年月日・学校名・住所・電話番号を取らない。年齢は「13歳以上・18歳未満は保護者の同意」の確認（`users.agreed_at`）だけ。
- 運営者が記録の中身を読める管理画面を作らない。登録は既定で**一般公開**（`config('suiri.invite_only')` が false。Google アカウントがあればだれでも登録できる）なので、運営者の知らない人も使う前提で守る。招待制に戻したとき（`.env` の `SUIRI_INVITE_ONLY=true`）の名簿（`invitations`。メールアドレスを持つ）の管理もコマンドで（`invite:add`・`invite:list`・`invite:remove`）。利用規約の「登録できる人」の文は、この設定で出し分ける（`views/legal/terms`）。
- 施術の事例や効果を公開・共有する機能を作らない。画像を上げる機能は作らない（作るなら位置情報を消し、nginx の multipart の止めを外す相談から）。

## 注意書き（文は config に1か所。画面に直書きしない）

| 置き場所 | 中身（要点） |
|---|---|
| すべての入力欄の下（`<x-ui.privacy-note>`、常に小さく） | ここに書くのは自分の観察と考え。ほかの人の名前・連絡先・顔写真、病名・通院のことは書かない。人は「同僚A」のように書く |
| 仕事の場面の振り返り（初回はダイアログ、以降は入力欄の上） | 自分の見方を振り返るためのもの。お客さまの記録（カルテ）には使えない。名前・イニシャル・会員番号・生年月日・写真・病名・通院や服薬は書かない |
| フッター・このアプリについて | 日常の観察と考え方を練習する道具。医療機器ではなく、病気の診断・治療・予防を目的としていません。体の不調は医師に |
| このアプリについて（効果） | 使えば考える力が伸びる、とは約束しない。記録を残すための道具 |
| カレンダーとつなぐボタンの前（`suiri.calendar.consent`） | 送るのはタスクの題名と日時とリンクと、どのタスクの予定かを見分ける番号（`suiri_task_id`）だけ（番号はアプリの中の通し番号で、利用者の記録の中身ではないと添える。確かめるタスクは決まった題名）。本文は送らない。読むのは今日から14日先までの予定の題名と時刻だけ（今日の画面と確かめる日の提案のため。5分だけ覚える）。Google は米国の会社。いつでも解除できる |
| プライバシーポリシー | 上の送る・読む項目と同じ中身。Google API Services User Data Policy（Limited Use を含む）に従う一文。「4. ほかの人に渡すこと」に、本人がつないだ AI のときの決まり（`legal.partials.ai-connect`。下の「自分の AI とつなぐ窓口」と同じ中身） |
| ChatGPT・Claude とつなぐ同意の画面（`views/oauth/authorize`・`ai_connect.consent`） | AI の名前（自己申告）・許可したあとに戻る先の住所・読めるもの（事件・手がかり・見立て・予想と答え合わせ・屋根裏の棚）・読めないもの（仕事の場面の事件・ほかの人の記録）・記録が渡る会社と国とそのポリシー・「自分で始めたときだけ進める」注意 |
| 設定の「ChatGPT・Claude とつなぐ」の枠（`ai_connect.panel`） | 読むだけ・仕事の場面は見せない・AI に正誤を決めさせない・渡った記録はその会社の決まりで扱われる（AI の記憶に残ることがある）・いつでもやめられる |
| 初回の同意 | 13歳以上。18歳未満は保護者の同意。利用規約とプライバシーポリシーに同意 |

- 効果を誇張しない（「頭が良くなる」「脳トレ」などは `bin/check` が止める。否定の形「〜とはお約束しません」は通る）。
- ワトソンの W-5：電話番号・メールアドレスの形、「様」「さん」のつく名前らしきものがあれば「ほかの人がわかる情報ではありませんか？」と知らせる（**保存は止めない**）。

## ログ・応答に本文を出さない

- アプリのログとエラー通知に入力の本文（題名・手がかり・見立て・予想の文・メモ・棚の文）を書かない。リクエストの本文を記録しない。ログに書くのは id・種類・件数・エラーの種類だけ（`bin/check` が `Log::` と本文の列の組み合わせを止める）。
- ログイン後の応答には `Cache-Control: private, no-store`。セキュリティのヘッダ（nosniff・SAMEORIGIN・Referrer-Policy・Permissions-Policy・本番の HSTS）を付ける。
- 記録の消え方はプライバシーポリシーの数字（`config/legal.php`）と実際の設定をそろえる。**守れない日数を約束しない**：
  - アクセスの記録（nginx などの箱の出力）：日数では区切らず、Docker の記録の大きさの上限（`docker-compose.yml` の `x-logging`：10MB × 5）を超えた古いものから消える（`legal.access_log`）
  - アプリのエラーの記録：90 日（本番の `LOG_STACK=daily`・`LOG_DAILY_DAYS=90`、`legal.error_log_days`）
  - カレンダーから読んだ予定（今日の予定・確かめる日の提案のこれからの予定。題名と時刻）：`cache` 表に5分だけ。期限の過ぎた行は `cache:prune-expired` が5分ごとに消す
- 題名などの入力を GET の住所（URL）に載せない（アクセスの記録に残るため）。本文を持って画面を移るときは POST で受けて一度きりの入力にする（`tasks.draft`・`cases.draft`）。

## 退会・ダウンロード

- 退会（`Actions/Account/DeleteAccount`）：Google のトークンを取り消し（revoke）、その利用者の行を**すべて物理削除**する（`cascadeOnDelete` で子の表まで）。ほかの端末のログインの記録（`sessions`）と、メールアドレスを持つ招待の名簿の行（招待制のときに入れたもの。ある場合）も消す。Google にある専用カレンダーは消さない（ポリシーに書いてある）。
- 退会では、AI とつないだ許可（Laravel Passport の `oauth_access_tokens`・`oauth_refresh_tokens`・`oauth_auth_codes`・`oauth_device_codes` のその人の行）も**明示して消す**（Passport の表には `cascadeOnDelete` が付いていない。`DeleteAccount::forgetAiGrants`）。AI の自己登録の行（`oauth_clients`）は利用者の記録ではないので残し、使われなければ `ai:prune-apps` が消す。
- 自分のデータを JSON ですべてダウンロードできる（`Actions/Account/ExportUserData`）。**新しい表・列を足したら、書き出しにも足す**。トークンは書き出さない（つないでいる AI は `ai_connections` に名前・戻る先の住所・最後につながった日時だけ。通行証の番号は出さない）。
- バックアップは 7 日で消える。プライバシーポリシーの数字と同じにする。

## 外部に送らない

- 運営者の側から外部に送るのは Google（ログインと、カレンダーのタスクの題名・日時・戻るリンク・見分けるための番号）だけ。Google から受け取るのはログインの名前・メール・アイコン・ID と、今日から14日先までの予定の題名と時刻（`suiri.calendar.agenda_fields` で項目を絞る。確かめる日の提案の題名は画面に出すだけ）と、専用カレンダーの予定の日時だけ。アクセス解析・広告のタグを入れない。
- **運営者から外部の AI に本文を送る機能は作らない**（アプリの中で AI の API を呼ばない）。置くのは、利用者が自分の AI（ChatGPT・Claude）に読ませる窓口（下の節）と、端末に写すだけのボタンだけ。

## 自分の AI とつなぐ窓口（読むだけの MCP。決まりの全体は `rules/ai-connect.md`）

- **本人の操作で、本人がつないだ AI が読みに来る**形にする（運営者が選んで送らない）。つなぐ前に同意の画面で、行き先の会社と国（OpenAI・Anthropic はどちらも米国）とその会社のポリシーへのリンクを示す（外国にある第三者への提供の同意で求められる情報に寄せる）。法律の確かめはオーナー（専門家）に頼む。
- **窓口で見せるもの**：本人の事件のうち仕事の場面でないもの（なぞ・状態・場面・結論）・その手がかり・見立て（○× の手がかりの番号つき）・予想と答え合わせ（文・確かさ・確かめる日・書いた日時・結果・一言・見落とし）・屋根裏の棚（事件と結んでいない知識と、見える事件から来た知識）・推理手帳のその画面の住所。
- **窓口で見せないもの**：仕事の場面の事件と、そこにつながる予想・棚の知識（施術の場面には体のことが混ざりうる）・ほかの人の記録・相棒モードで見せ合う前の見立てと予想・タスク・ふりかえり・名推理カードの推理・設定・Google から受け取った予定・カレンダーの鍵・メールアドレスなどのアカウントの情報。
- 預かるのは許可の記録（つないだ AI の名前・戻る先・許可した日時と期限）と通行証の番号だけ。通行証の中身は保存しない。通行証は1時間・更新の札は30日（`ai_connect.tokens`）。取り消したものは毎日、期限の切れたものは更新の札の期限を過ぎてから消す（`passport:purge`）。数字はプライバシーポリシーが `config/ai_connect.php` から引く。
- 写すボタン（「AI に相談する用に写す」）は端末のクリップボードに写すだけで、アプリからは何も送らない。仕事の場面の事件では出さない。頼み方の文に「名前などの個人情報は書かない」を入れ、ボタンの近くに「貼る前に名前などが入っていないか見てね」と出す。
- 送る項目を増やしたら、プライバシーポリシーの「取得する情報・外部サービス」と、カレンダー連携の前の説明も直す。
- 運営者の氏名・連絡先は `config/legal.php` の【】に運営者が自分で書く（AI が作って書かない）。
