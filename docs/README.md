# 推理手帳 解体新書

![推理手帳](images/cover.png)

このフォルダは、手帳アプリ「推理手帳」（英語の副題 Deduction Notebook）を **まるごと理解するための説明書** です。
アプリが何をするのか、どこに何があるのか、どう動いているのかを、プログラムを学び始めた人にもわかるように、省略せずに説明します。

推理手帳は、シャーロック・ホームズのものの見方を、本を読んで終わりにせず **毎日の生活で練習して記録する** ための手帳です。**観察 → 仮説 → 予想 → 確かめる → 振り返る** の手順を、タスク管理に組み込んでいます。気になる出来事を **事件** にし、**手がかり**（見た／聞いた／なかった）から **見立て** を2つ以上立て、「**もしそうなら** 〜が見えるはず」という予想に確かめる日を付けて Google カレンダーの専用カレンダーに入れ、**答え合わせ** で見立てを直します。外れは **ノーベリ帳** に、わかった一般則は **屋根裏の棚** にためます。くわしくは [1. 鳥観図](guide/01-birdseye.md) から読んでください。

> **ブラウザで読むなら [guide.html](guide.html)**：この説明書の全部（`README.md`・この目次・1〜12章・設計書5つ・調査の入口）を1つの HTML にまとめた版です。ダブルクリックで開くだけで、左の目次から章へ飛べ、図や写真もそのまま見られます（インターネットにつながっていなくても読めます）。中身は Markdown から `node tools/docs-html/build.mjs` で作っているので、直すときは元の Markdown を直します。

**この説明書の書き方：** どの章も「この章でわかること」→ 節 →「次に読む章」の順です。節は「**役目（一言）→ たとえると → 中身**」の順なので、まず役目とたとえだけを拾い読みして全体をつかみ、気になった所の中身を読む、という読み方ができます。難しい言葉は、最初に出たところで言い換えています。わからない言葉は [9. 用語集](guide/09-glossary.md) で引けます。

**AI 向けの読み込みのしくみ：** `CLAUDE.md` は、Claude Code や Codex がこのフォルダで作業を始めると **いつも自動で読み込まれる** 場所に置いてあります。ここには、どの作業でも守ることと「どの作業ならどの決まりを読むか」の道案内の表だけを書いています。分野ごとの決まり（言葉と表の対応・層の分け方・画面・個人情報・Google・ChatGPT と Claude とつなぐ窓口・手引きの教材・テスト・コメント・本番・ドキュメントの11個）は `.claude/rules/` に分けてあり、その分野のファイルを読んだり直したりしたときだけ読み込まれます（関係のない決まりで頭がいっぱいにならないように）。

**決まりは機械でも確かめています：** 書いた決まりのうち、機械で判定できるもの（受付で検証しない・使わない言葉・1ファイルの行数の上限・コメントの抜け・秘密の値・ドキュメントのリンク切れ など）は、`bin/check` が確かめます。AI が作業するときのフックと、git のコミットの前に自動で動きます（[8章](guide/08-operations.md) の 8-5・8-6）。
