# 調査（推理手帳を作る前に調べたこと）

推理手帳の要件を決める前に、7つのテーマを手分けして調べた報告書です（2026-10-31）。要件定義書（[../design/requirements.md](../design/requirements.md)）は、ここから作りました。

## 調べる前の前提

- 目的：日常の中でホームズのものの見方（観察 → 仮説 → 予想 → 確かめる → 振り返る）を練習できるアプリ。本を読んで終わりにせず、タスク管理に組み込んだ形にする。
- 使う人：子どもと一緒に、論理的に考える練習をしている保護者とその子ども。施術者が自分の見方を振り返る使い方も考える。
- 取り入れたい考え方：ホームズの原作の推理（とくに演繹）と、細谷功『具体と抽象』のような、具体と抽象を行き来して考える練習。
