# 12. ChatGPT・Claude とつなぐ（読むだけの窓口）

## この章でわかること

- 推理手帳のアプリの中では AI を使っていないこと。そのうえで、自分の ChatGPT・Claude から推理手帳の記録を読んで相談できる「窓口」があること
- 何ができて、何ができないか（読んで提案するだけ。書き込みはできない）
- しくみ：MCP・OAuth・動的クライアント登録・通行証・4つの道具
- AI に見せるもの・見せないもの（仕事の場面の事件は見せない）
- 利用者向けのつなぎ方（ChatGPT・Claude）と、つなぐのをやめる方法
- どのプランでも使える「AI に相談する用に写す」ボタンの使い方
- 作る人向け：コードの置き場所・本番で確かめる方法・困ったとき

> 要件は [要件定義書](../design/requirements.md) の 4-11、決まりは [`.claude/rules/ai-connect.md`](../../.claude/rules/ai-connect.md) と [`.claude/rules/privacy.md`](../../.claude/rules/privacy.md)、言葉は [言葉のルール](../design/words.md) の 1-3、画面の部品は [部品説明書](../design/components.md) の 8-2・8-3 にあります。

## 12-0. ひとことでいうと

**役目：** 推理手帳に「AI 用の受付の小窓」（`https://suiri.agi-japan.com/mcp`）を1つ置きます。利用者が自分の ChatGPT や Claude の設定にこの住所を入れると、推理手帳のログイン（Google）と同意の画面を通ったあと、その AI が本人の記録を**読んで**、ほかの見立てや確かめ方を提案してくれます。

**たとえると：** 推理手帳の事務所に、本人の代理人（AI）だけが使える小窓を作るようなものです。代理人は、本人から預かった**通行証**を毎回見せて、本人の手帳を見せてもらいます。小窓から見えるのは、仕事の棚を除いた本人の棚だけ。代理人は手帳を**読むだけ**で、ページに書き込んだり、破ったり、答え合わせの欄を埋めたりはできません。通行証は、本人がいつでも設定の画面で無効にできます。

**中身：**

| 決めたこと | 中身 | 理由 |
|---|---|---|
| アプリの中の AI | 使わない（ワトソンのひとことも入力の提案も、決まった規則） | 日常の出来事には正解のデータがなく、AI の採点はもっともらしく見えても確かめられない（[要件定義書](../design/requirements.md) の 5章） |
| つなぐ AI | 利用者が**自分で**契約している ChatGPT・Claude | AI の料金は利用者のプランの中。推理手帳は AI の API を持たない |
| AI の役目 | 候補を出すことだけ（ほかの見立て・見立てを見分ける確かめ方・まだ集めていない手がかり） | 当たり外れは本人が現実で確かめる。AI に正誤を決めさせない |
| できること | 読むだけ | 子どもや施術者の記録を、AI の言い間違いで壊さないため |
| 見せる範囲 | 本人の記録のうち、仕事の場面の事件を除くもの | 施術の場面には体のことが混ざりうる。外国の会社の AI に渡さない |

## 12-1. 何ができるか・できないか

**役目：** つなぐ前に、AI に何を頼めて何を頼めないかを知っておきます。

| できること（AI に頼めること） | 例 |
|---|---|
| 事件の一覧を見て、相談したい事件を探す | 「推理手帳の捜査中の事件を一覧にして」 |
| 1つの事件の中身を読んで、ほかの見立てを出してもらう | 「体操着の事件を見て、ほかの見立てを1つか2つ出して」 |
| 見立てを見分ける確かめ方を考えてもらう | 「見立て1と2のどちらかを見分けるには、何を見ればいい？」 |
| まだ集めていない手がかり（とくに「なかった」こと）を教えてもらう | 「見落としていそうな手がかりはある？」 |
| 答え合わせ待ちの予想を見て、何を見れば確かめられるか一緒に考える | 「今日確かめる予想を見せて。どこを見ればいい？」 |
| 屋根裏の棚から、使えそうな知識を探してもらう | 「棚に、朝の準備に関係する知識はある？」 |

| できないこと | 理由 |
|---|---|
| 記録を書く・直す・消す（手がかり・見立て・予想を足すことも） | 窓口に書き込みの道具を置いていない。足したいときは、AI の提案を見て本人が推理手帳の画面で書く |
| 答え合わせ・取り下げ・○× を付ける・見立ての状態を変える | 当たり外れは本人が現実で確かめる。AI に判定させない |
| 予想の文と確かさを変える | 保存したあとは書き換えない決まり（後知恵を防ぐ）。考えが変わったら新しい予想を立てる |
| 仕事の場面の事件を読む | 窓口から見えない（ないのではない） |
| 相棒モードで見せ合う前の見立てを読む | 見せ合うまでは隠す決まり（推理手帳の画面と同じ） |
| タスク・カレンダー・ふりかえり・設定を読む | 相談の役目に要らない |

## 12-2. しくみ

**役目：** 「自分の AI に、自分の記録だけを、読むだけで見せる」を、パスワードを渡さずに実現するしくみです。

**たとえると：** 銀行の窓口で「この人は私の代理人です」と委任状を書くようなものです。推理手帳のパスワード（Google のログイン）を AI に教えるのではなく、推理手帳が「この AI に、この人の記録を読ませてよい」という**通行証**を出し、AI はそれを毎回見せます。

### MCP（AI とアプリをつなぐ決まり）

MCP（Model Context Protocol）は、AI がアプリの「道具」を呼ぶための決まりです。ChatGPT も Claude もこの決まりに対応しているので、同じ1つの住所（`/mcp`）で両方とつながります。推理手帳では Laravel 公式の部品 **laravel/mcp** で窓口を作っています。

### 4つの道具（どれも読むだけ）

| 道具の名前 | 何をするか | AI に渡すもの（要点） |
|---|---|---|
| `list_cases` | 事件の一覧（状態と題名の言葉で絞れる） | なぞ・状態・場面・手がかりの数・見立ての数・答え合わせ待ちの予想の数・推理手帳のその画面の住所 |
| `get_case` | 1つの事件の中身 | なぞ・手がかり（見た／聞いた／なかった）・見立て（○× の付いた手がかりの番号）・予想と答え合わせ・わかったこと |
| `list_due_predictions` | 答え合わせ待ちの予想（確かめる日が来たもの。何日先まで含めるかを選べる） | 予想の文・確かさ・確かめる日・書いた日時・もとの見立てと事件 |
| `search_attic` | 屋根裏の棚（「つまり？」と「たとえば？」）を言葉で探す | つまり？・たとえば？・生まれた事件 |

AI が最初に読む「窓口の説明」と、道具ごとの説明文には、「候補を出すだけで正誤を判定しない」「予想は書いたあと変えられないので、新しい予想の案として出す」「病気や体の状態を見分けない」「ほかの人の名前を書かない」「仕事の場面の事件は見えない」を書いてあります（`config/ai_connect.php`）。

### OAuth（パスワードを渡さずに許可を出すしくみ）

つなぐときの流れです。①〜④と⑥⑦は AI の会社のサーバーと推理手帳のやりとりで、⑤だけが利用者のブラウザで起きます。

```text
 ChatGPT / Claude                     推理手帳（suiri.agi-japan.com）                    Google
 ─────────────────                    ──────────────────────────────                    ──────
 ① 通行証なしで /mcp を呼ぶ ─────────▶ 401「通行証が要ります。出し方の案内はここ」
 ② 案内を読む ──────────────────────▶ 「同意の画面・通行証・自己登録の住所はここ」
 ③ 自己登録（POST /oauth/register）─▶ 戻り先が chatgpt.com・claude.ai・claude.com なら登録の番号を返す
 ④ 利用者のブラウザで同意の画面を開かせる
 ⑤ 利用者のブラウザ：
      ├ ログインしていない → Google でログイン ───────────────────────────────────▶ 選ぶ
      │   ◀─（初めてなら利用規約に同意）→ 同意の画面へ戻る
      └ 同意の画面「ChatGPT に、あなたの事件の記録を読ませてよいですか？」
           ├ 許可する → 引換券を持って ChatGPT へ戻る
           └ やめる   → 「やめた」と ChatGPT へ戻る（何も渡らない）
 ⑥ 引換券を通行証に引き換える（POST /oauth/token）─▶ 通行証（1時間）＋ 更新の札（30日）
 ⑦ 通行証を見せて /mcp の道具を呼ぶ ─▶ 本人の記録（仕事の場面を除く）
```

| 言葉 | 意味 |
|---|---|
| **動的クライアント登録** | AI が自分で「私は ChatGPT です。許可のあとはこの住所に戻してください」と登録すること（③）。利用者が登録の番号を手で写す手間がない。推理手帳は、戻り先が ChatGPT と Claude の住所のときだけ受け付ける（`config/mcp.php`） |
| **引換券（認可コード）と PKCE** | 同意したあとに一度だけ使える札と、それを途中で盗まれても使えないようにする合言葉のしくみ。AI だけが合言葉を知っている |
| **通行証（アクセストークン）** | AI が道具を呼ぶたびに見せる文字列。**1時間**で切れる |
| **更新の札（リフレッシュトークン）** | 通行証が切れたとき、つなぎ直さずに新しい通行証に取り替える札。**30日**で切れ、使うたびに新しい札に替わる |
| **範囲（スコープ）** | 通行証で何ができるか。推理手帳は「窓口を読む」（`mcp:use`）の1つだけ |

通行証を出す係は Laravel 公式の **Laravel Passport** です。推理手帳のログインは今までどおり Google だけで、AI 用のパスワードはありません。

### 守り

| 守り | 中身 |
|---|---|
| 戻り先を3つに絞る | 自己登録できるのは、戻り先が `https://chatgpt.com`・`https://claude.ai`・`https://claude.com` の AI だけ。ほかの住所は断る（よその人が作った偽の AI に通行証が渡らないように） |
| 同意を飛ばさない | 初めての AI には必ず同意の画面を出す。つなぐのをやめたあとも、もう一度同意の画面から |
| 同意の画面の注意 | AI の名前はだれでも名乗れるので、画面で「許可したあとに戻る先」の住所を太く出す。「自分で AI の設定から『つなぐ』を押したときだけ進めてね。人から送られてきたリンクなら『やめる』を押してね」と出す |
| 規約に同意した人だけ | 同意の画面は、推理手帳にログインして利用規約に同意した人だけが開ける |
| よその画面からの呼び出しを断る | ブラウザのよその画面から `/mcp` を呼ばれたら断る（AI の会社のサーバーからの呼び出しだけを通す） |
| 回数の上限 | 道具の呼び出しは1人1分120回まで。案内・通行証・自己登録にも上限がある |

## 12-3. 見せるもの・見せないもの

**役目：** AI の会社に渡る記録の範囲を、はっきり決めておきます。

| 見せるもの | 見せないもの |
|---|---|
| 自分の事件のうち、日常と親子の場面のもの（なぞ・状態・結論） | **仕事の場面の事件**と、そこにつながる予想・屋根裏の棚の知識 |
| その手がかり・見立て（○× の手がかりの番号つき） | ほかの人の記録 |
| 予想と答え合わせ（文・確かさ・確かめる日・書いた日時・結果・一言・見落とし） | 相棒モードで見せ合う前の見立てと予想 |
| 屋根裏の棚（事件と結んでいない知識と、見える事件から来た知識） | タスク・ふりかえり・名推理カードの推理・設定 |
| 推理手帳のその画面に戻る住所 | Google カレンダーから読んだ予定・カレンダーの鍵・メールアドレス |

- 仕事の場面の事件やほかの人の事件の番号を AI が指定しても、「見つかりません」と返します。「ない」のか「見せない」のかがわからない、同じ文です。
- 推理手帳が預かるのは、つないだ AI の名前・戻る先の住所・許可した日時と期限、通行証の番号だけです（通行証の中身は保存しません）。データのダウンロード（設定の画面）には、つないでいる AI の名前・戻る先・最後につながった日時が入ります。
- AI に渡った記録は、その会社の決まりと、利用者のプランの設定（会話を学習に使うか・記憶の機能など）で扱われます。ChatGPT のメモリなど AI 側の記憶に残ることもあります。推理手帳からは消せないので、AI 側の設定で消します。くわしくは推理手帳の [プライバシーポリシー](https://suiri.agi-japan.com/privacy) の「4. ほかの人に渡すこと」です（元の文は `src/resources/views/legal/partials/ai-connect.blade.php`）。

## 12-4. つなぎ方（利用者向け）

**役目：** 利用者が自分の ChatGPT（または Claude）に、推理手帳をつなぐ手順です。設定の画面の「ChatGPT・Claude とつなぐ」の枠にも同じ手順があります。

> **画面の名前は変わることがあります。** ChatGPT・Claude の設定の項目名は、英語のまま書いています（2026-10 時点）。見つからないときは、似た名前の項目を探してください。

窓口の住所は、どちらも同じです。

```text
https://suiri.agi-japan.com/mcp
```

### ChatGPT の場合

1. ChatGPT の **Settings** → **Apps & Connectors**（または **Connectors**）を開く。
2. **Advanced settings** → **Developer mode** を入れる。
3. **Create** を押して、名前に「推理手帳」、**MCP Server URL** に上の住所を入れる。**Authentication** は **OAuth** を選んで作る。
4. 推理手帳の画面が開いたら、Google でログインする（初めてなら利用規約に同意する）。
5. 同意の画面で「許可したあとに戻る先」が `chatgpt.com` になっているか見て、**許可する**を押す。
6. 新しいチャットで推理手帳を選んで、「体操着の事件を見て、ほかの見立てを出して」のように頼む。

- ChatGPT は、プランによってはつなげない・読むだけになることがあります（2026-10 の OpenAI のヘルプでは、自分で足す窓口を使えるプランが限られています）。項目が出てこないときは、事件の画面の「AI に相談する用に写す」（12-6）を使います。
- 推理手帳の道具が変わったあとは、ChatGPT のアプリの詳細で **Refresh** を押すと、道具の説明を読み直します。

### Claude の場合

1. Claude の **Settings**（または **Customize**）→ **Connectors** を開く。
2. **Add custom connector** を押して、名前に「推理手帳」、URL に上の住所（最後に `/` を付けない）を入れて **Add**。
3. 推理手帳の画面が開いたら、Google でログインする。
4. 同意の画面で戻る先が `claude.ai` になっているか見て、**許可する**を押す。
5. チャットの **＋** → **Connectors** で推理手帳を入れて、相談する。

### つないだあと

- 設定の画面の「つないでいる AI」に、AI の名前・戻る先の住所・最後につながった日が出ます。
- 通行証は1時間で切れますが、AI が更新の札で自動で取り替えるので、ふだんはつなぎ直す必要はありません。30日使わなかったときは、もう一度つなぎます。

## 12-5. つなぐのをやめる（取り消し方）

**役目：** AI に記録を読ませるのを、すぐにやめます。

1. 推理手帳の **設定** を開き、「ChatGPT・Claude とつなぐ」の枠の「つないでいる AI」を見る。
2. やめたい AI の行の **つなぐのをやめる** を押し、確かめの文で **やめる** を押す。
3. 「◯◯ とつなぐのをやめたよ。」と出たら終わり。

- その AI の通行証と更新の札がすべて無効になり、**次の呼び出しから読めなくなります**（推理手帳は、道具を呼ばれるたびに取り消したかを確かめているため）。
- また使うときは、AI の側でつなぎ直します。同意の画面がもう一度出ます。
- AI の側（ChatGPT・Claude の設定）でつないだアプリを外すこともできます。退会すると、許可の記録もすべて消えます。

## 12-6. AI に相談する用に写す（写すボタン）

**役目：** 窓口を使えないプランの人でも、どの AI にでも相談できるようにするボタンです。

**たとえると：** 手帳の1ページをコピー機で写して、自分で相談相手に渡すようなものです。推理手帳は写すだけで、どこにも送りません。

1. 事件の画面の「あとでできること」にある **AI に相談する用に写す** を押す。
2. 「写したよ。ChatGPT に貼ってね」と出たら、自分の ChatGPT や Claude のチャットに貼る。
3. 貼る前に、名前などほかの人がわかることが入っていないか見る。

写す文には、なぞ・手がかり（番号つき）・見立て（合う／合わない手がかりと予想つき）・わかったことと、頼み方の文（「正誤は判定せず、ほかの見立てと、見立てを見分ける確かめ方の案を出してください。…名前などの個人情報は書かないでください」）が入ります。

- 仕事の場面の事件では、このボタンは出ません。
- 相棒モードで見せ合う前は、見立てを写しません。
- 写せなかったとき（ブラウザが許可しない・古いブラウザ）や JavaScript が動かないときは、「写す文を見る」を開いて、文を長押しして写します。

## 12-7. できないこと・気をつけること

- **AI の答えは候補です。** 正しいことを推理手帳の運営者は約束しません（推理手帳の [利用規約](https://suiri.agi-japan.com/terms) の第4条）。当たり外れは、確かめる日に自分で確かめて、推理手帳の答え合わせに書きます。
- **AI は記録を書けません。** よい提案があったら、推理手帳の画面で本人が手がかり・見立て・予想として書きます。予想の確かさ（どのくらい自信ある？）も自分で決めます。
- **病気や体の状態の判断には使えません。** 窓口の説明でも、AI に見分けたり言い切ったりしないよう伝えています。
- **つなぐかどうかは自分で決めます。** つながなくても、推理手帳の機能はすべて使えます。
- 手元の開発環境（http://localhost:8086）からは、ChatGPT・Claude とつなげません（AI の会社のサーバーから https で届く必要があるため）。手元では機能テストで確かめます。

## 12-8. コードの置き場所（作る人向け）

**役目：** 窓口のどの部分がどのファイルにあるかの地図です。くわしい索引は [`docs/ai/codemap.md`](../ai/codemap.md) の 1-11・2-15。

| もの | 場所 | 中身 |
|---|---|---|
| AI の側の住所 | `src/routes/ai.php` | 案内（`/.well-known/…`）・自己登録（`/oauth/register`）・通行証（`/oauth/token`）・窓口（`/mcp`）。laravel/mcp がミドルウェアのグループなしで読むので、セッションも CSRF もない。窓口には通行証の確かめ（`auth:api`・`mcp:use`）が必ず付く |
| 利用者のブラウザで開く住所 | `src/routes/web/ai.php` | 同意の画面（`/oauth/authorize`。ログインと規約の同意が要る）・つなぐのをやめる（`DELETE /settings/ai/{app}`） |
| 窓口と道具 | `src/app/Mcp/Servers/SuiriServer.php`・`src/app/Mcp/Tools/*` | 道具は受付（コントローラー）と同じく薄く：形を確かめる → `Queries/Ai` で組み立てる → 形にして返す |
| 見える事件の決まり | `src/app/Queries/Ai/VisibleCases.php` | 「本人の・仕事の場面でない」の1か所。ほかの組み立て役はここを使う |
| Passport の設定 | `src/app/Providers/AiConnectServiceProvider.php` | Passport の住所を止めて自分で置き直す・同意の画面・通行証の期限・範囲・回数の上限 |
| 同意の画面 | `src/resources/views/oauth/authorize.blade.php`・`src/app/Support/Ai/ConsentView.php` | Passport が渡す値を、画面向けの値（AI の名前・戻る先・会社と国）に詰め替える |
| 設定の枠 | `src/resources/views/components/settings/ai-panel.blade.php`（`ai-app-row`・`ai-steps`） | つないでいる AI は `Queries/Ai/ConnectedAppsQuery`、やめるのは `Actions/Ai/RevokeAiAccess` |
| 写すボタン | `src/resources/views/components/case/ai-copy.blade.php`・`src/app/Support/Ai/ConsultText.php`・`src/resources/js/parts/ai-copy.js` | 写す文の組み立てと、クリップボードに写す動き |
| 言葉と数字 | `src/config/ai_connect.php`・`src/config/mcp.php` | 窓口の説明・道具の説明文・画面の言葉・通行証の期限・戻り先の3つ |
| 掃除 | `src/routes/console.php`・`src/app/Console/Commands/PruneAiApps.php` | 毎日：取り消した・期限の切れた通行証を消す（`passport:purge`）、使われなかった自己登録を消す（`ai:prune-apps`） |
| テスト | `src/tests/Feature/Ai/*` | 外の AI には届かない。テスト用の鍵と偽の通行証で、案内・自己登録・同意の画面・窓口・道具・設定・取り消しを確かめる |

## 12-9. 本番で確かめる

**役目：** 本番に載せたあと、窓口が正しく動いているかを、記録に触れずに機械で確かめます。

**初回だけ：** 本番で通行証に署名する鍵を作ります（[10章](10-deploy-aws.md) の「更新するとき」の「初回だけ」）。

```bash
docker compose exec app php artisan passport:keys
```

**手元のパソコンから（だれでもできる。記録には触れない）：**

```bash
# ① 窓口の案内：resource が https://suiri.agi-japan.com/mcp と完全に同じか（Claude は1字でも違うとつながらない）
curl -s https://suiri.agi-japan.com/.well-known/oauth-protected-resource/mcp
# ② 通行証を出す係の案内：住所がすべて https で、S256・registration_endpoint・token_endpoint があるか
curl -s https://suiri.agi-japan.com/.well-known/oauth-authorization-server
# ③ 通行証なしの窓口：401 と WWW-Authenticate（resource_metadata つき）が返るか（トップへの 302 ではないか）
curl -si -X POST https://suiri.agi-japan.com/mcp -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
# ④ よその戻り先の自己登録が断られるか（400 invalid_redirect_uri）
curl -si -X POST https://suiri.agi-japan.com/oauth/register -H 'Content-Type: application/json' \
  -d '{"client_name":"check","redirect_uris":["https://evil.example/cb"]}'
# ⑤ GET の窓口は 405
curl -si https://suiri.agi-japan.com/mcp
```

**つないで確かめる（Claude は無料のプランでもつなげるので、最初の確かめに向きます）：**

| 確かめること | 見方 |
|---|---|
| 仕事の場面の事件が見えない | 仕事の場面の事件の題名を名指しで頼んでも「見つかりません」になる |
| 判定しない | 「どの見立てが正しい？」と聞いても、確かめ方の提案に戻る |
| 書けない | 「この予想を当たりにして」と頼んでも、道具がないので、推理手帳で書くよう案内される |
| やめるとすぐ効く | 設定 → つなぐのをやめる → AI で頼むと失敗し、つなぎ直すと同意の画面がもう一度出る |
| 1時間後 | 通行証が切れたあとも、つなぎ直さずに使える（更新の札が効いている） |
| ログ | `docker compose logs app` に題名・本文が出ていない |

## 12-10. 困ったとき

| 見えること | よくある理由 | 確かめること・直し方 |
|---|---|---|
| ChatGPT に Developer mode・Create が出ない | プランがカスタムの窓口に対応していない | 写すボタン（12-6）を使う。Claude ならつなげることがある |
| つなぐときにエラー（500） | 本番で `passport:keys` をまだ打っていない | [10章](10-deploy-aws.md) の「初回だけ」 |
| 同意の画面の前にトップへ戻される | 推理手帳にログインできていない（招待制に切り替えているときは、名簿にないメールアドレス） | Google で、推理手帳に登録したアカウントを選ぶ（招待制のときは名簿にあるアカウント） |
| 「許可したあとに戻る先」が見覚えのない住所 | 人から送られたリンク | **やめる**を押す。自分で AI の設定から「つなぐ」を押したときだけ進める |
| 自己登録で 400 | 戻り先が chatgpt.com・claude.ai・claude.com 以外 | 正しい AI の画面からつないでいるか。AI の会社が戻り先を変えたなら `config/mcp.php` と同意の画面の会社の一覧を直す |
| 1時間ごとにつなぎ直しを求められる | AI が更新の札を使っていない | 本番で確かめ、続くなら通行証の期限（`config/ai_connect.php` の `tokens`）を見直す。数字を変えたらポリシーの文も変わる（config から引いている） |
| 道具の説明が古い | AI が前の説明を覚えている | ChatGPT はアプリの詳細で **Refresh**、Claude はコネクタを付け直す |
